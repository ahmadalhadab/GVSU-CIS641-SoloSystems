# Software Requirements Specification

## Project: Cargo Logistics System

### 1. Introduction
This project is a simple Cargo Logistics System. The goal is to help a transportation company manage shipments, drivers, and vehicles.

### 2. Purpose
The purpose of this system is to make daily logistics work easier, reduce mistakes, and organize shipment information.

### 3. Functional Requirements
1. The system shall allow dispatchers to create new shipments.
2. The system shall allow dispatchers to assign drivers to shipments.
3. The system shall store driver and vehicle information.
4. The system shall allow users to update shipment status.
5. The system shall allow dispatchers to view delivery information.

### 4. Non-Functional Requirements
1. The system should be easy to use.
2. The system should protect user information.
3. The system should respond quickly.
4. The system should be available when needed.

### 5. Users
- Dispatcher
- Driver
- Administrator

### 6. Conclusion
This system will help organize cargo transportation and make it easier to manage daily operations.
