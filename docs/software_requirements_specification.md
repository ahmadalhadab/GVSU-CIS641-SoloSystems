# Software Requirements Specification

## Project: Cargo Logistics System

# Overview

This document describes the requirements for the Cargo Logistics System. The system is designed to help manage shipments, drivers, vehicles, and shipment status.

# Functional Requirements

1. Shipment Management
 FR1: The system shall allow a dispatcher to create a shipment with pickup and delivery locations.
 FR4: The system shall allow a dispatcher to view the details and current status of each shipment.

2. Driver and Vehicle Assignment
 FR2: The system shall allow a dispatcher to assign an available driver and vehicle to a shipment.

3. Shipment Status
 FR3: The system shall allow a driver to update the shipment status, such as picked up or delivered.

# Non-Functional Requirements

1. Performance
 NFR1: The system shall display a shipment details page within three seconds under normal operating conditions.

2. Security
 NFR2: The system shall require users to sign in before they can access shipment information.

3. Compatibility
 NFR3: The system shall be usable on both desktop computers and mobile phones.

4. Reliability
 NFR4: The system shall save shipment updates without losing entered information during normal operation.
